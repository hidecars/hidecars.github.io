# 令和6年度春期 午後 問1 情報セキュリティ／リモート環境のセキュリティ対策

## 1. 覚えるキーワード3つ
- ゼロトラスト：社内・社外を問わず、いかなる通信も信頼しないセキュリティの考え方
- SIEM：複数機器のログを一元的に集約・相関分析し、インシデントを迅速に検知する仕組み
- EDR：端末での不審な挙動を検知し、ネットワーク遮断やプロセス終了を行う対策

## 2. 状況
- 生徒からのハイブリッド型授業の要望と、従業員からのテレワーク勤務の要望に応える環境を整える。機器の保守終了(EOL)も近づいている。
- 課題は、パッチ適用の判断の遅れ、境界型防御の限界、インシデントを迅速に検知する仕組みがないこと。
- ゼロトラストの考え方でSaaSを利用し、貸与PC・IDaaS・SIEM・EDRを導入する。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 境界型防御の限界に対応する | —（設問2(1)は正答率が低かった） | 境界の内側を信頼する考えをやめ、すべての通信を信頼しない「ゼロトラスト」へ移行する | いかなる通信も信頼しない |
| インシデントを迅速に見つけたい | — | 各機器のログを一元的に集めて相関分析する（SIEM）。設問3(2)は正答率が高かった | セキュリティインシデントの発生を迅速に検知する |
| 未知の攻撃を端末で止めたい | — | パターンマッチングで防げないゼロデイ攻撃には、端末の挙動を見るEDRで遮断・停止する | ゼロデイ攻撃、ファイルレスマルウェア |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| ゼロトラスト | すべての通信を信頼せず、常に確認するセキュリティモデル |
| 境界型防御 | 社内と外部の境界で守る考え方 |
| SIEM | ログを集約・相関分析して異常を検知する仕組み |
| EDR | 端末の不審な挙動を検知し、遮断・停止する対策 |
| IDaaS | ID管理やシングルサインオンをクラウドで提供するサービス |
| 多要素認証 | 異なる種類の要素（知識・所持など）を組み合わせて本人確認する方式 |

## 6. 思い出しクイズ
- Q1 境界型防御の限界に対応する、すべての通信を信頼しない考え方は → ゼロトラスト
- Q2 複数機器のログを集約・相関分析し、インシデントを迅速に検知する仕組みは → SIEM
- Q3 SaaS移行で不要になったパッチ管理の作業は → セキュリティパッチ提供の調査及び適用の判断
- Q4 ゼロデイ攻撃などを検知したとき、EDRが行う対処は → 端末をネットワークから遮断し、不審なプロセスを終了する
- Q5 IDとパスワードに、スマホのワンタイムパスワードを組み合わせる認証方式は → 多要素認証（2要素認証）

※採点講評：設問2(1)は正答率が低かった。設問3(2)は正答率が高く、SIEMの理解がうかがえた。
