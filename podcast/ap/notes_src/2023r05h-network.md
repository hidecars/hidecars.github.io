# 令和5年度春期 午後 問5 ネットワーク／Webサイトの増設

## 1. 覚えるキーワード3つ
- デフォルトルート：宛先が不定のパケット(インターネット宛てなど)の転送先を、1つにまとめて書いた経路
- ゾーン転送：DNSが管理する領域(ゾーン)の情報を、プライマリDNSからセカンダリDNSへコピーすること
- TTL：DNSの応答をキャッシュしておく時間。切替え前に小さくしておくと、変更が早く行き渡る

## 2. 状況
- F社のデータセンターbにあるWebサイトbで、WebAPサーバbの処理能力が足りず、顧客から応答遅延の苦情が増えた。
- 対策として、c-DCに同じ構成のWebサイトcを増設し、DNSラウンドロビンで負荷を分散する。
- 設問は、現行の経路、アクセス先のFQDN、DNSの設定、メンテナンス時の顧客への影響を問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 宛先が不定のパケットの行き先 | —（設問1(1)は正答率がやや低かった） | デフォルトルートが指すネクストホップ(FWf)へ送る。経路表に1つにまとめて書いてある | デフォルトルート |
| DNSサーバ間で情報をそろえる | —（設問3(1)のcは正答率が低かった） | ゾーンの情報をプライマリからセカンダリへコピーするのがゾーン転送 | ゾーン |
| WebAPサーバの停止を伴うメンテナンス | —（設問3(3)は正答率が低かった） | DNSのキャッシュが更新されても、更新前からログインしている顧客は影響を受ける。停止前にログイン中の利用者がいないことを確認する | ログイン中の利用者 |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | デフォルトルートのネクストホップ機器 | FWf |
| 1(2) | 運用PCからDNSサーバbまでの経由機器 | L3SW、FWb、L2SWb |
| 2(1) a | 顧客と同じアクセス先の公開用FQDN | miap.example.jp |
| 2(2) | 広域イーサ網経由のアクセス先FQDN | apb.f-sha.example.lan |
| 3(1) b | 運用PCに登録する代替のDNSサーバ | DNSサーバc |
| 3(1) c | DNSサーバ間で情報をコピーする仕組み | ゾーン |
| 3(1) d | 事前に小さくするレコードの属性 | TTL |
| 3(2) | Webサイトを1つ停止したときの顧客への影響 | システムの応答速度が低下することがある |
| 3(3) | WebAPサーバ停止前に確認すること | ログイン中の利用者がいないこと |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| DNSラウンドロビン | 1つのFQDNに複数のIPアドレスを登録し、順番に返して負荷を分散する方式 |
| FQDN | ホスト名とドメイン名をすべて書いた名前 |
| デフォルトルート | 経路表にない宛先へ送るときの、既定の転送先 |
| ゾーン | DNSサーバが管理する名前の範囲 |
| TTL | DNSの応答をキャッシュしてよい時間 |
| L3SW | IPアドレスで経路を判断して転送するスイッチ |

## 6. 思い出しクイズ
- Q1 宛先が不定のパケットの転送先を1つにまとめた経路は → デフォルトルート
- Q2 プライマリDNSからセカンダリDNSへ、ゾーンの情報をコピーすることは → ゾーン転送
- Q3 切替え前に小さい値へ変えておくDNSレコードの属性は → TTL
- Q4 WebAPサーバを1台止めたとき、顧客に起きることは → 応答速度が低下することがある
- Q5 WebAPサーバを止める前に確認することは → ログイン中の利用者がいないこと

※採点講評：設問1(1)は正答率がやや低く、デフォルトルートが宛先不定のパケットの転送先をまとめた経路であることの理解が問われた。設問3(1)のcと3(3)は正答率が低かった。
