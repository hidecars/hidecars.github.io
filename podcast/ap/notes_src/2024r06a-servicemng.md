# 令和6年度秋期 午後 問10 サービスマネジメント／サービスデスクの立上げ

## 1. 覚えるキーワード3つ
- 一次解決率：利用者の問合せに、最初の連絡で回答できた割合
- 問合せ対応ノウハウ集：過去の問合せ記録をもとに、問合せ内容・対応手順・回答内容を整理した資料
- 標準変更：あらかじめ承認された変更。定型の手順書でサービスデスクが対応できる

## 2. 状況
- 営業支援サービスのサービスデスクを立ち上げる。サービス要求の増加で、サービス課の業務量が著しく増えて圧迫されている。
- サービス課の業務をできるだけサービスデスクへ移管し、サービス課の負担を軽くする。
- 営業員が最初にサービスデスクへ問合せ、答えられないものはサービス課へエスカレーションする。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| サービス課の業務をサービスデスクへ移す | 「標準変更の中に定型化できるものがないか」を調べる（標準変更は移管済み） | 通常変更の中に、標準変更にできるものがないかを調べる | 通常変更、標準変更 |
| 必要な要員工数を計算する | 平均件数のまま計算し、需要の増加と集中への余裕を入れない | 来年度の増加分と、集中度合いを見た余裕の両方を条件に入れて算出する | 2割増加、2割の余裕 |
| 移管の成果を測る | — | 最初の連絡で解決できた割合（一次解決率）をKPIにし、スキルトランスファーで要員にドキュメントを説明する | 一次解決率、サービスデスク用ドキュメントの説明 |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | 一次解決率の説明(a) | 最初の連絡で回答 |
| 1(2) | スキルトランスファーで行うこと(b) | サービスデスク用ドキュメントの説明 |
| 2(1) | 回答に使う資料(c) | 問合せ対応ノウハウ集 |
| 2(2) | 調査の目的／内容 | サービス課の業務を極力サービスデスクに移管するため／通常変更の中に標準変更にできるものがないか調べる |
| 3 | 課題の解消状況を測る指標 | 一次解決率 |
| 4 | 1日の必要工数(人日) | 3 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| 標準変更 | あらかじめ承認された、影響の小さい定型の変更 |
| 通常変更 | 事前に承認されておらず、個別の判断が必要な変更 |
| スキルトランスファー | 業務のノウハウを他の要員へ伝えること |
| 一次解決率 | 最初の連絡で問合せを解決できた割合 |
| KPI | 目標の達成度を測る重要業績評価指標 |
| サービス要求 | 利用者からの問合せや、標準変更などの依頼 |

## 6. 思い出しクイズ
- Q1 一次解決率を上げるために、問合せへの回答に使う資料は → 問合せ対応ノウハウ集
- Q2 サービス課の業務を移管するため、標準変更にできるものがないか調べる対象は → 通常変更
- Q3 課題の解消状況を測るために設定する指標は → 一次解決率
- Q4 来年度の需要2割増・余裕2割を見込んだ1日の必要工数(人日)は → 3
- Q5 スキルトランスファーで、サービスデスク要員に説明する対象は → サービスデスク用ドキュメント

※採点講評：設問2(2)の調査内容では「標準変更の中に…」という解答が散見された。設問4は、需要の増加と集中度合いの余裕を条件に入れていない解答が散見された。
