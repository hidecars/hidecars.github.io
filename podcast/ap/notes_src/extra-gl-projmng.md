# 用語集・プロジェクトマネジメント／プロジェクトマネジメント用語7語 PMBOK第7版からEVMまで

## 1. 覚えるキーワード3つ
- CCPM：余裕を集めて全体で管理
- ベロシティ：1反復で終わる作業量
- EVM：SV＝EV−PV、CV＝EV−AC

## 2. 状況
- シラバス強化用語集（2026/10/30版）のうち「プロジェクトマネジメント」の7語を扱う。
- 令和8年度からCBT方式（科目A=午前、科目B=午後）。シラバスはVer.7.2。
- 使い方：まず「ひとこと」を声に出して読み、「午後での問われ方」を確認する。

## 3. 分野の核心

| 用語 | ひとこと | ポイント |
|---|---|---|
| PMBOK第7版 | プロジェクトマネジメントの知識体系。第7版は「12の原則」と「8つのパフォーマンス領域」で構成される。 | 第6版までの「プロセス（手順）中心」から、「価値の実現」と「原則」中心に変わった。 |
| CCPM | 各作業の余裕（バッファ）を外して最後にまとめ、全体で管理する手法。 | 人は余裕があると使い切る（パーキンソンの法則）。バッファを統合すると無駄な消費を防げる。 |
| バーンダウンチャート | 残りの作業量が日ごとに減っていく様子を表すグラフ。 | 計画線より上なら遅れ、下なら進んでいる。残作業は残チケット数などで数える。 |
| ベロシティ | アジャイル開発で、1回の反復（スプリント）で完了できる作業量。 | 過去のベロシティから、残りの作業が何回の反復で終わるかを見積もる。 |
| スコープクリープ | 正式な手続を経ずに、作業範囲（スコープ）が少しずつ広がっていくこと。 | コストや納期の超過の原因になる。変更は変更管理の手続で承認してから行う。 |
| ステークホルダーエンゲージメント | 利害関係者を特定し、関与の度合いを適切に保つ活動。 | 影響力と関心の高さで分類し、伝える内容や頻度を変える。 |
| EVM | 出来高（EV）で進捗とコストを管理する手法。PVは計画値、ACは実コスト。 | SV＝EV−PV（マイナスなら遅れ）、CV＝EV−AC（マイナスなら予算超過）。 |
