# 用語集・ネットワーク／ネットワーク用語9語 HTTP/3からIEEE 802.1Xまで

## 1. 覚えるキーワード3つ
- HTTP/3（QUIC）：UDP上で動く
- SNMPトラップ：機器から自発的に通知
- IEEE 802.1X：接続時に端末を認証

## 2. 状況
- シラバス強化用語集（2026/10/30版）のうち「ネットワーク」の9語を扱う。
- 令和8年度からCBT方式（科目A=午前、科目B=午後）。シラバスはVer.7.2。
- 使い方：まず「ひとこと」を声に出して読み、「午後での問われ方」を確認する。

## 3. 分野の核心

| 用語 | ひとこと | ポイント |
|---|---|---|
| HTTP/3（QUIC） | HTTP/3は、UDP上のQUICという通信方式を使う新しいHTTP。 | TCPより接続確立が速く、1つの通信の遅れが他の通信を止めにくい。暗号化（TLS 1.3相当）が組み込まれている。 |
| TLS 1.3 | 通信を暗号化するTLSの最新版。 | 手順（ハンドシェイク）が短くなり速い。古く弱い暗号方式は使えなくなった。 |
| SASE／ZTNA | SASEはネットワークとセキュリティ機能をクラウドでまとめて提供する考え方。ZTNAはゼロトラストに基づくリモートアクセス。 | VPNで社内に入れる方式と違い、ZTNAは利用者と端末を検証してから、許可されたアプリだけに接続させる。 |
| SWG | 社外へのWebアクセスを中継し、有害サイトの遮断やマルウェア検査を行う仕組み（クラウド型が多い）。 | 従来は社内のプロキシで行っていた検査を、場所を問わず受けられる。テレワークで必要になる。 |
| Wi-Fi 6E／Wi-Fi 7／WPA3 | Wi-Fi 6E・7は6GHz帯も使える新しい無線LAN規格。WPA3は無線LANの新しい暗号化方式。 | 6GHz帯は混雑が少なく速い。WPA3はパスワード総当たりに強く、6GHz帯の利用に必須。 |
| IPv6（IPoE） | IPoEはPPPoEのような認証の手順を使わず、IPv6で直接インターネットにつなぐ接続方式。 | PPPoEの混雑する装置を通らないため、混む時間帯でも速度が落ちにくい。 |
| MQTT | IoT機器向けの軽量な通信プロトコル。発行（publish）と購読（subscribe）の方式。 | 機器（パブリッシャ）はブローカーにデータを送り、受け手（サブスクライバ）はブローカーから受け取る。 |
| SNMPトラップ | ネットワーク機器が、しきい値超過などの異常を管理装置へ自発的に通知する機能。 | 通常のSNMPは管理装置から問い合わせる（ポーリング）。トラップは機器側から送る。 |
| IEEE 802.1X | LANに接続する端末や利用者を、接続時に認証する規格。 | 認証サーバ（RADIUS）と組み合わせ、認証されない端末はネットワークに入れない。 |

## 6. 思い出しクイズ
- Q1 HTTP/3（QUIC）とは → HTTP/3は、UDP上のQUICという通信方式を使う新しいHTTP。
- Q2 TLS 1.3とは → 通信を暗号化するTLSの最新版。
- Q3 SASE／ZTNAとは → SASEはネットワークとセキュリティ機能をクラウドでまとめて提供する考え方。ZTNAはゼロトラストに基づくリモートアクセス。
- Q4 SWGとは → 社外へのWebアクセスを中継し、有害サイトの遮断やマルウェア検査を行う仕組み（クラウド型が多い）。
- Q5 Wi-Fi 6E／Wi-Fi 7／WPA3とは → Wi-Fi 6E・7は6GHz帯も使える新しい無線LAN規格。WPA3は無線LANの新しい暗号化方式。
- Q6 IPv6（IPoE）とは → IPoEはPPPoEのような認証の手順を使わず、IPv6で直接インターネットにつなぐ接続方式。
- Q7 MQTTとは → IoT機器向けの軽量な通信プロトコル。発行（publish）と購読（subscribe）の方式。
- Q8 SNMPトラップとは → ネットワーク機器が、しきい値超過などの異常を管理装置へ自発的に通知する機能。
- Q9 IEEE 802.1Xとは → LANに接続する端末や利用者を、接続時に認証する規格。
