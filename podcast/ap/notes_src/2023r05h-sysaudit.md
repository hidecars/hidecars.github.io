# 令和5年度春期 午後 問11 システム監査／工場在庫管理システムの監査

## 1. 覚えるキーワード3つ
- 手作業の統制：システムの統制は、自動化された統制と、人が行う手作業の統制を組み合わせる。どちらの統制かを見分ける
- 実地棚卸リスト：実際に数えた棚卸の結果。在庫データとの差異を確かめて、網羅性を検証する
- 他人の利用者ID：現場のPCの使われ方から、他人のIDが使われていないかを確かめる

## 2. 状況
- Y社は、情報の信頼性を高め不正を防ぐため、工場の在庫管理の運用状況についてシステム監査を行う。
- 予備調査で、現場PCのログインの放置、CSVによる手動のデータ入力、出庫データの自動生成、棚卸差異の調整などの課題が見つかった。
- 設問は、アクセス管理の実地観察、入庫の手作業の検証、出庫の標準使用量の妥当性、棚卸リストの網羅性、不要・不正な利用者IDの検出を問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 統制の種類を見分ける | —（設問2は正答率が低かった） | システムの統制は、自動化された統制だけでなく、人為的な手作業の統制と組み合わせる。設問に対応する統制がどちらかを本文から読み取る | 手作業、自動化統制 |
| 在庫の網羅性を確かめる | — | 実地棚卸リストと在庫データを突き合わせ、在庫の差異を確かめる | 実地棚卸リスト、在庫データ |
| 利用者IDの使われ方を確かめる | —（設問5のhは正答率がやや低かった） | 工場の作業現場のPCの利用状況から、IDがどう使われているかを読み取り、他人の利用者IDを検出する | 他人の利用者ID |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |

| 3 d | 確かめる対象(空欄) | イ(在庫の差異) |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| システム監査 | 専門性と客観性のある監査人が、情報システムを点検・評価する活動 |
| 自動化統制 | システムの機能に組み込まれた、自動で働く統制 |
| 手作業の統制 | 人が行って確かめる統制 |
| 実地棚卸 | 実際の在庫を数え、帳簿と照合する作業 |
| 利用者ID | システムを使う人を識別するための識別子 |
| 監査手続 | 監査の要点を確かめるための具体的な手順 |

## 6. 思い出しクイズ
- Q1 システムの統制は、自動化された統制と何を組み合わせるか → 人が行う手作業の統制
- Q2 在庫の網羅性の確認で、在庫データと突き合わせるリストは → 実地棚卸リスト
- Q3 現場のPCの利用状況から検出したい利用者IDは → 他人の利用者ID
- Q4 システムの機能に組み込まれた統制は → 自動化統制
- Q5 設問2で正答率が低かったのは、何を読み取る問題か → 対応する統制が自動化か手作業か

※採点講評：設問2は正答率が低く、システムの統制が自動化された統制と手作業の統制の組合せであることの理解が求められた。設問5のhは正答率がやや低かった。
