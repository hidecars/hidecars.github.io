## 2. 核心：用語ごとの判断ルール

### 1. EVM（アーンドバリューマネジメント）

出来高（EV）を使って、進捗とコストを同じ金額の尺度で管理する手法。

![EVMの3つの値と、そこから出す指標](img/extra-gl-projmngb-1.svg)

- PV（計画価値）：今日までに終える予定だった作業の予算。EV（出来高）：今日までに実際に終えた作業の予算。AC（実コスト）：実際にかかった費用。BAC：全体の予算。
- SV＝EV−PV。マイナスなら進捗の遅れ（R5秋：EV−PVが負→遅れ）。
- CV＝EV−AC。マイナスならコスト超過。
- SPI＝EV÷PV、CPI＝EV÷AC。1未満なら悪い。
- 完成時総コストの見積り（今の効率が続く場合）：EAC＝BAC÷CPI。
- 午後での問われ方：進捗遅れの判断では EVとPV を比べる（R7秋 午後問9）。
- 誤り：進捗の判断でACとPVを比べる誤り。進捗はEVとPVで比べる。
- 誤り：式の順番の誤り。差も比も、必ずEVが先（左・分子）。

| 指標 | 式 | 悪いとき |
|---|---|---|
| SV（進捗差異） | EV−PV | マイナス＝遅れ |
| CV（コスト差異） | EV−AC | マイナス＝予算超過 |
| SPI | EV÷PV | 1未満＝遅れ |
| CPI | EV÷AC | 1未満＝超過 |
| EAC | BAC÷CPI | BACより大きいと予算超過の見込み |

数値例：BAC 1,000万円、PV 500万円、EV 400万円、AC 500万円。SV＝400−500＝−100万円（遅れ）、CV＝400−500＝−100万円（超過）、SPI＝400÷500＝0.8、CPI＝400÷500＝0.8、EAC＝1,000÷0.8＝1,250万円。

### 2. リスク対応と期待金額価値（EMV）

リスクは、起きると目標に影響する不確かな事象。悪い影響（脅威）と良い影響（好機）がある。

![脅威への4つの対応と、デシジョンツリーでのEMV](img/extra-gl-projmngb-2.svg)

- 脅威への対応：回避（原因を取り除く）、転嫁（保険や契約で第三者に移す）、軽減（発生確率や影響を下げる）、受容（何もしないか予備を持つ）。
- 好機への対応：活用、共有、強化、受容。脅威と好機に共通するのは「受容」（第6版以降は「エスカレーション」も共通）。
- 期待金額価値（EMV）＝発生確率×金額の合計。デシジョンツリーでは、EMVが大きい案を選ぶ。
- コンティンジェンシー計画：リスクが発生したときに実行する対応を、前もって決めておく計画。
- 誤り：保険をかけるのを「軽減」とする誤り。保険は「転嫁」。

数値例：新規開発案は成功確率0.6で利益10億円、失敗確率0.4で損失2億円。EMV＝0.6×10＋0.4×(−2)＝6−0.8＝5.2億円。確率0.5で8億、0.5で−2億なら、4−1＝3億円。

### 3. WBSとスコープの管理

WBSは、プロジェクトの成果物と作業を階層的に分解した図。スコープは、プロジェクトで行う作業と作る成果物の範囲。

- WBSの最上位から最下位まで、すべての作業を漏れなく含める（100%ルール）。
- スコープ記述書に書くもの：成果物、受入基準、除外事項（やらないこと）など。
- スコープの管理（コントロール）：計画したスコープと実際を比べ、差があれば変更要求を出す（R4秋・R6秋に同じ問い）。
- 誤り：「スコープの管理＝WBSを作ること」は誤り。WBSの作成は計画、管理は実績との比較と変更要求。

### 4. CCPM

CCPM（Critical Chain Project Management）は、各作業の余裕（バッファ）を外して最後にまとめ、全体で管理する手法。

- 人は余裕があると使い切る（パーキンソンの法則）。バッファを統合すると無駄な消費を防げる。
- 午後での問われ方：遅れそうなとき → 延期ではなく、余裕のあるチームから要員をシフトする（R7春 午後問9）。

### 5. バーンダウンチャートとベロシティ

アジャイル開発の進み具合を見る道具。

![バーンダウンチャートの読み方](img/extra-gl-projmngb-3.svg)

- バーンダウンチャート：残りの作業量が日ごとに減っていく様子を表すグラフ。計画線より上なら遅れ、下なら進んでいる。残作業は残チケット数などで数える。
- 午後での問われ方：グラフから遅れ日数を読む計算、タスク追加時の「チケット発行」が出た（R7秋 午後問9）。
- ベロシティ：アジャイル開発で、1回の反復（スプリント）で完了できる作業量。過去のベロシティから、残りの作業が何回の反復で終わるかを見積もる。
- 午後での問われ方（ベロシティ）：「残作業÷ベロシティ＝必要な反復回数」の計算で出やすい。
- 補足の例：残作業が60ポイント、ベロシティが20ポイント/スプリントなら、60÷20＝3スプリントで終わる見込み。

### 6. スコープクリープとステークホルダーエンゲージメント

- スコープクリープ：正式な手続を経ずに、作業範囲（スコープ）が少しずつ広がっていくこと。コストや納期の超過の原因になる。変更は変更管理の手続で承認してから行う。
- 午後での問われ方：「仕様変更要望をどう扱うか」→ 一覧で管理し、影響を評価して承認を得る、と書く。
- ステークホルダーエンゲージメント：利害関係者を特定し、関与の度合いを適切に保つ活動。影響力と関心の高さで分類し、伝える内容や頻度を変える。
- 午後での問われ方：「誰の合意が必要か」「どの段階で関与させるか」を本文の登場人物から読み取る。
