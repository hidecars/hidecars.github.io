# 令和4年度秋期 午後 問1 情報セキュリティ／マルウェアへの対応策

## 1. 覚えるキーワード3つ
- ICMPエコー要求の連続送信：宛先IPアドレスのホストが稼働しているかを調べる通信。連続して出ていれば、マルウェアの侵入後の探索を疑う
- 感染PCの隔離：内部探索を防ぐ緊急措置として、マルウェアに感染したPCを隔離する
- EDRのログ分析：EDRが保存するログを分析すれば、侵入後の被害を早期に解明できる

## 2. 状況
- IT製品卸売のP社は、社外で多発するマルウェアXに対し、現行の対策ソフトやSPF、週1回のログ検査では検知・防止が難しい。
- パッチ適用とログ検査を速め、侵入の早期発見、侵入後の活動の抑止、被害の把握のためにEDRを導入し、対応策を整える。
- 設問は、機器の役割、踏み台攻撃、ネットワーク探索、侵入の検知と被害の解明を問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| ネットワーク内部を探索される | —（設問2(1)は正答率がやや低かった） | ICMPエコー要求にポート番号はない。宛先のホストが稼働しているかを調べる通信で、稼働中のホストのIPアドレスが分かる | ICMPエコー要求 |
| 侵入を疑う事象を見つける | —（設問3(1)は正答率が低かった） | 本文のマルウェアXの動作から、ICMPエコー要求パケットの連続した送信は、業務処理ではなく侵入後の活動と判断する | 連続した送信 |
| 感染後の対処と被害の把握 | — | 内部探索を防ぐため、感染したPCを隔離する。被害の解明には、EDRが保存するログを分析する | 隔離、EDR |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) a | 通信を許可・遮断する機器 | ア(FW) |
| 1(1) b | ドメイン認証を行う機器 | ケ(メール中継サーバ) |
| 1(1) c | パッチを配布する機器 | ク(配布サーバ) |
| 1(2) | 踏み台にされる攻撃 | ア(DNSリフレクション攻撃) |
| 2(1) | 探索で得られる情報 | 稼働中のホストのIPアドレス |
| 2(2) | SYN送信の目的 | ウ(攻撃対象のサービスの稼働状態を知るため) |
| 2(3) | SPFで発見できない理由 | ア(送信者のドメインが詐称されたものでない) |
| 3(1) | 侵入を疑う検知事象 | ICMPエコー要求パケットの連続した送信 |
| 3(2) | 内部探索を防ぐ緊急措置 | マルウェアに感染したPCを隔離する |
| 3(3) | 被害を早期に解明する実施事項 | EDRが保存するログの分析 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| EDR | 端末の挙動を監視し、検知・調査を支援する仕組み |
| SPF | 送信元のドメインが正しいか、メールの送信元IPで確認する仕組み |
| ICMPエコー要求 | 相手のホストが稼働しているかを調べる通信(ping) |
| DNSリフレクション攻撃 | DNSサーバを踏み台にして、標的へ大量の応答を送る攻撃 |
| 内部探索 | 侵入後に、内部のホストやサービスを調べる活動 |
| C&Cサーバ | マルウェアに指示を出す攻撃者のサーバ |

## 6. 思い出しクイズ
- Q1 ICMPエコー要求で得られる情報は → 稼働中のホストのIPアドレス
- Q2 ICMPエコー要求の連続送信は、何を疑う事象か → マルウェアの侵入後の活動
- Q3 内部探索を防ぐ緊急措置は → 感染したPCを隔離する
- Q4 被害を早期に解明するために分析するのは → EDRが保存するログ
- Q5 DNSサーバを踏み台にする攻撃は → DNSリフレクション攻撃

※採点講評：設問1は正答率が高かった。設問2(1)は正答率がやや低く、ICMPエコー要求がホストの稼働確認に使われることの理解が問われた。設問3(1)は正答率が低かった。
