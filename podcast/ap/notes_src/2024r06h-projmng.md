# 令和6年度春期 午後 問9 プロジェクトマネジメント／IoT活用プロジェクトのマネジメント

## 1. 覚えるキーワード3つ
- PoC（概念実証）：実現に不確かな要素が多いとき、立ち上げ前に実現可能性を検証すること
- スコープクリープ：管理しないと、プロジェクトの作業範囲が無計画に広がってしまうこと
- トリプルコンストレイント：品質はスコープ・コスト・スケジュールの影響を受ける。変更時は3要素を調整して品質を守る

## 2. 状況
- P農業組合が、いちごの栽培の生産性を上げるため、W社のIoTシステムとA社のAI分析SaaSを導入する。
- 環境データや気象予報から最適な制御パラメータを自動で出し、栽培装置へ送るサービスを作る。
- P農業組合・W社・A社が連携し、農家がこのサービスを活用して、よりよい収穫を得ることを目指す。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 立ち上げ前にPoCをやるか決める | — | 実現に不確かな要素が多いときは、事前に検証してリスクを下げる | 本サービスの実現に不確かな要素が多い |
| 作業範囲の追加・変更が重なる | — | ある会社の範囲の変更が、連携する会社の範囲にも波及する。追加のルールを決めて管理する(設問2(2)は正答率がやや高かった) | Kセンサーの種類を増やすと開発規模が増える／W社側の変更がA社側に影響する |
| 範囲が変わっても品質を守る | —（設問2(3)は正答率がやや低かった） | 品質はスコープ・コスト・スケジュールの3要素から影響を受ける。変更時は3要素を調整する | コスト、スケジュール |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| PoC | 新しい構想や技術の実現可能性を事前に検証すること |
| SaaS | クラウド経由でソフトウェアの機能を提供する形態 |
| スコープクリープ | 作業範囲が管理されずに無計画に広がること |
| ベースライン | 変更や進捗を評価するための基準となる計画値 |
| トリプルコンストレイント | 品質に影響するスコープ・コスト・スケジュールの3要素 |
| ガイド機能 | 利用者が自分で設定や操作をできるよう支援する機能 |

## 6. 思い出しクイズ
- Q1 立ち上げ前にPoCを実施した理由は → 本サービスの実現に不確かな要素が多いから
- Q2 スコープクリープが起きやすい、W社とA社の関係上の要因は → W社側の作業スコープの変更がA社側の作業スコープに影響すること
- Q3 スコープ管理で、スコープのほかに基準とする2つは → コスト、スケジュール
- Q4 プロジェクト完了時点で導入効果を評価できない理由は → いちごを収穫するまで評価できないから
- Q5 サービス開始後に青年部2名が担当する役割は → 農家がガイド機能を活用できるようにする支援

※採点講評：設問2(2)は正答率がやや高く、設問2(3)は正答率がやや低かった。
