# 令和4年度秋期 午後 問10 サービスマネジメント／サービス変更の計画

## 1. 覚えるキーワード3つ
- 成果の定義：変更で得る成果は、運用開始後に達成を検証できる、測定可能な定量的指標で決める。手段は成果ではない
- 作業工数の算出：追加されたジョブは、運用担当者の確認作業の時間で工数を出す。システム処理時間は足さない
- 運用費予算の超過：1か月当たりの平均作業工数の増加が10%を超えると、運用費用の予算を超える

## 2. 状況
- 食品販売のD社は、売掛金の回収率を上げるため、受注時の与信チェックを追加する。受注システムに、与信管理サブシステムと与信管理DBを置く。
- 新パッケージの導入で、委託先M社の要員の管理、与信の問合せ、信用情報を取得するジョブなどの作業が増える。
- 工数を算出すると、サービスデスク業務の増加が10%を超え、運用費の予算を超過する問題が見つかった。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 変更で得られる成果を決める | N社パッケージの導入や与信DBの構築を成果とする（設問1で散見） | パッケージ導入や与信DB構築は、成果を出すための手段。成果は「売掛金の回収率を高める」のように、測定できる指標で定義する | 売掛金の回収率 |
| 作業工数を算出する | システム処理時間を足して計算する（設問3(1)のdで散見） | ジョブの工数は、運用担当者の確認作業の実施時間から出す。計算式は複雑ではないので、落ち着いて計算する | 確認作業 |
| 予算への影響を判断する | — | 1か月当たりの平均作業工数の増加が10%を超えるなら、サービスデスク業務で運用費用の予算を超過する | 10%超 |

| 設問 | 問われていること | 決め手のキーワード |

| 1 | 今回の変更で得られる成果 | 売掛金の回収率を高める |
| 2 a | 漏れていた作業項目の番号 | 6(機能アップグレードする場合の対応) |
| 2 | 項目6に追加する作業 | 業務変更のための業務設計 |
| 3(1) b | 利用者管理の月平均作業工数 | 1.1 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| サービス変更 | サービス内容を変え、運用に影響する変更 |
| 与信管理 | 取引先の支払能力を調べ、取引の限度を決める管理 |
| 作業工数 | 作業にかかる人の時間 |
| 成果 | 変更で得られる効果。測定可能な指標で定義する |
| サービスデスク | 利用者からの問合せを受ける窓口 |
| 運用費用の予算 | 運用にかけられる費用の上限 |

## 6. 思い出しクイズ
- Q1 今回の変更で得られる成果は → 売掛金の回収率を高める
- Q2 パッケージ導入や与信DBの構築は、成果か手段か → 手段
- Q3 追加ジョブの工数に加えてはいけない時間は → システム処理時間
- Q4 サービスデスク業務の月平均作業工数は → 46.2
- Q5 作業工数の増加がいくらを超えると、予算を超過するか → 10%

※採点講評：設問1は正答率が平均的だったが、パッケージ導入や与信DBの構築を成果とする解答が散見された。設問3(1)のdは正答率が低く、システム処理時間を加算した解答が散見された。
