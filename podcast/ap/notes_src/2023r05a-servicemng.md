# 令和5年度秋期 午後 問10 サービスマネジメント／サービスレベル

## 1. 覚えるキーワード3つ
- SLAのサービスレベル目標：販売部とSLAを結び、利用者が実感する時間を、サービスレベル項目として目標にする
- 内部供給者との目標の合意：販売部との目標を達成するために、サービス課は、開発課・運用課とも目標を合意する
- サービス回復時間：回復時間には、システム開発課以外が行う作業の時間も含まれるので、目標を見直す

## 2. 状況
- セキュリティ機器メーカーのE社で、販売部の提案作成に時間がかかる課題を解決するため、製品管理システムと連動する新システムへ改修する。
- 販売部とSLAを合意し、外部委託先のY社(サービスデスク)や内部供給者(開発課・運用課)と、回復時間などの目標をそろえる。
- サービス開始直後に問合せが急増するおそれがあるため、FAQの掲載などで対応する。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 販売部とSLAを結ぶ | — | 販売担当者が提案情報の作成を要求してから、納期と価格の情報が表示されるまでの時間を、サービスレベル項目に追加する | 要求してから表示されるまでの時間 |
| 内部供給者との合意 | —（設問2(2)は正答率がやや低かった） | 販売部とのサービスレベル目標を達成するには、内部供給者との項目・目標の合意が必要 | 内部供給者 |
| 回復時間の目標を見直す | — | 回復時間には、システム開発課以外で行う作業の時間も含まれる。そのため、内部供給者との目標を見直す | 回復時間、システム開発課以外 |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 | 販売部から追加要求されたサービスレベル項目 | ウ(要求してから納期と価格が表示されるまでの時間) |
| 2(1) a | 表1の空欄 | ア(契約書) |
| 2(2) | 内部供給者と合意する理由 | 表1のサービスレベル目標の達成には、内部供給者との目標の合意が必要だから |
| 2(3) | サービスレベル目標を見直す理由 | サービス回復時間にはシステム開発課以外で実施する作業の時間も含まれるから |
| 3(1) | 問合せ件数の削減が必要な理由 | サービスデスク要員の体制が確保できないから |
| 3(2) | FAQ掲載による利用者の利点 | サービスデスクのサポート時間帯以外でも、利用者が疑問を解決できる |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| SLA | サービス提供者と利用者が合意するサービスレベルの取り決め |
| サービスレベル目標 | SLAに定める、達成すべき水準 |
| 内部供給者 | 自社内で、サービスの提供を支える部門 |
| 外部供給者 | サービスの提供を支える、外部の委託先 |
| サービスデスク | 利用者からの問合せを受け付ける窓口 |
| FAQ | よくある質問とその回答の一覧 |

## 6. 思い出しクイズ
- Q1 販売部とのSLAに追加した項目は → 要求してから納期と価格が表示されるまでの時間
- Q2 内部供給者と目標を合意する理由は → 販売部とのサービスレベル目標を達成するため
- Q3 回復時間の目標を見直す理由は → システム開発課以外で実施する作業の時間も含まれるから
- Q4 問合せ件数を減らす必要があった理由は → サービスデスク要員の体制が確保できないから
- Q5 FAQを載せる利用者側の利点は → サポート時間帯以外でも疑問を解決できる

※採点講評：設問2(2)は正答率がやや低く、内部供給者との合意が販売部との目標達成に必要であることの理解が問われた。設問3(1)も正答率がやや低く、「Y社の体制を増強する」という解答が散見された。1か月前にY社へ件数を提示するため、体制の増強はできないことを本文から読み取る必要がある。
