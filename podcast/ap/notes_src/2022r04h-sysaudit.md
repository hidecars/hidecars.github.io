# 令和4年度春期 午後 問11 システム監査／販売物流システムの監査

## 1. 覚えるキーワード3つ
- 売上訂正処理の権限：営業担当者に売上訂正の権限があると、不正のリスクがある。監査要点に対応する不正リスクを特定する
- 出荷指図データと売上データ：出荷指図データから売上データなどを生成している運用で、突き合わせて確かめる
- 出荷と在庫の整合性：外部倉庫システムから出荷実績データを入手できない場合、追加の手続で前提の信頼性を補う

## 2. 状況
- 食品製造販売会社のU社で、通信販売の拡大に伴い、倉庫業務のデータの信頼性を確かめる監査を行う。
- 外部倉庫の運営は複数の委託先が行っている。出荷実績データを受信せず、出荷指図データで売上データなどを生成する運用になっている。
- 営業担当者に売上訂正の権限があることなどのリスクに対し、コントロールの有効性を検証する監査手続を作る。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 不正リスクの指摘を理解する | 現状の不正リスクだけを述べる（設問2は正答率が低かった） | 監査要点を理解し、それに対応する不正リスクを特定する。営業担当者に売上訂正処理の権限があることが理由 | 売上訂正処理権限 |
| データの流れを確かめる | — | 出荷指図データから売上データなどを生成する流れを理解して、突き合わせる手続を考える | 出荷指図データ、売上データ |
| 出荷実績データが入手できない | —（設問4は正答率が平均的だった） | 前提の信頼性を補う追加手続として、出荷と在庫の整合性を確かめる | 出荷、在庫 |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 a | 売上データなどの生成元(空欄) | 出荷指図データ |
| 1 b | データの入手先(空欄) | 外部倉庫システム |
| 2 | 内部監査室長が指摘した理由 | 営業担当者に売上訂正処理権限があるから |
| 3 c・d | 突き合わせるデータ(順不同) | 出荷指図データ、売上データ |
| 4 e〜h | 追加の監査手続の対象 | e・fはカ、キ(順不同)、g・hはク、エ(順不同) |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| 出荷指図データ | 倉庫へ出荷を指示するデータ |
| 出荷実績データ | 実際に出荷した結果を表すデータ |
| 売上データ | 売上を計上するためのデータ |
| 監査要点 | 監査で確かめる、重要な点 |
| コントロール | 不正や誤りを防ぎ、見つけるための統制 |
| 外部委託先 | 業務を任せている外部の会社 |

## 6. 思い出しクイズ
- Q1 売上訂正処理の権限が営業担当者にあると、何が問題か → 不正のリスクがある
- Q2 売上データなどの生成元になるデータは → 出荷指図データ
- Q3 出荷指図データと突き合わせる対象の1つは → 売上データ
- Q4 出荷実績データを入手できないとき、追加で確かめる整合性は → 出荷と在庫
- Q5 監査手続を作るとき、まず理解するのは → 監査要点

※採点講評：設問2は正答率が低く、監査要点に対応した不正リスクを特定することが求められた。設問4は正答率が平均的で、出荷と在庫の整合性を理解することが期待された。
