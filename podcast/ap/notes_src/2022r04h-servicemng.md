# 令和4年度春期 午後 問10 サービスマネジメント／インシデント管理と問題管理

## 1. 覚えるキーワード3つ
- 階層的エスカレーション：解決目標時間に間に合わないときは、上位の担当者や管理者へ報告して判断を仰ぐ
- 既知の誤りと回避策：運用課が主体で既知の誤りを調べ、回避策を適用すれば、機能的エスカレーションの待機時間を減らせる
- 根本原因と解決策が特定された未解決の問題：回避策だけでは再発は止まらない。根本原因と解決策が分かっている未解決の問題を優先して解決する

## 2. 状況
- 公益法人の団体Xで、業務日報や情報共有をするWシステムの日締処理が異常停止した。
- 運用課のL君が階層的エスカレーションをせず、解決目標時間を超過した。
- 運用課の機能的エスカレーション前の手順、技術課との合意文書、問題管理での回避策の記録、再発防止の根本原因の解決が課題になった。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 解決目標時間を超えそう | — | 手順に従って、階層的エスカレーションを行う。行わなかったのが問題点 | 階層的エスカレーション |
| 機能的エスカレーションで待ち時間が出る | —（設問2(2)は正答率が低かった） | 運用課が主体的に、既知の誤りを調査して回避策を見つける。解決担当者だけで解決を試みる手順を、エスカレーションの前に追加する | 既知の誤り、回避策 |
| 再発インシデントを止めたい | 抽出条件を「回避策がある」とする(設問3(1)で多かった) | 回避策があっても、根本原因と解決策が特定されていなければ、再発は解消しない。条件は、根本原因と解決策が特定されている未解決の問題 | 根本原因、解決策 |

## 4. 解答キーワード一覧

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| インシデント管理 | サービスの中断を、素早く回復させる活動 |
| 問題管理 | インシデントの根本原因を見つけ、再発を防ぐ活動 |
| 階層的エスカレーション | 上位の管理者へ報告して、判断や資源を求めること |
| 機能的エスカレーション | より専門的な担当部署へ、解決を引き継ぐこと |
| 既知の誤り | 根本原因が分かっている問題。回避策があることが多い |
| RFC | 変更要求 |

## 6. 思い出しクイズ
- Q1 解決目標時間に間に合わないとき、L君が行わなかったことは → 階層的エスカレーション
- Q2 機能的エスカレーションの前に、運用課が行うことは → 既知の誤りを調査して、回避策を見つける
- Q3 再発を防ぐために優先して解決する問題は → 根本原因と解決策が特定されている未解決の問題
- Q4 回避策だけで、再発の問題は解決するか → 解決しない(根本原因の解決が必要)
- Q5 将来のインシデントを予防する活動は → プロアクティブな活動(傾向の分析)

※採点講評：設問2(2)は正答率が低く、運用課が既知の誤りを調査して回避策を適用する時間短縮が問われた。設問3(1)も正答率が低く、「回避策」を条件にした解答が多かった。
