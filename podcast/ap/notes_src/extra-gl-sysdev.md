# 用語集・情報システム開発／開発・その他用語6語 DevSecOpsから取適法まで

## 1. 覚えるキーワード3つ
- IaC：構成をコードで記述して自動構築
- リファクタリング：仕様を変えず内部を整理
- 取適法：下請法を改正・改称

## 2. 状況
- シラバス強化用語集（2026/10/30版）のうち「情報システム開発」の6語を扱う。
- 令和8年度からCBT方式（科目A=午前、科目B=午後）。シラバスはVer.7.2。
- 使い方：まず「ひとこと」を声に出して読み、「午後での問われ方」を確認する。

## 3. 分野の核心

| 用語 | ひとこと | ポイント |
|---|---|---|
| DevSecOps／CI/CD | CI/CDは、コードの統合・テスト・リリースを自動で継続的に行う仕組み。DevSecOpsはそこにセキュリティ検査を組み込む考え方。 | 脆弱性検査を開発の後工程ではなく早い段階（シフトレフト）で自動実行する。 |
| マイクロサービス | システムを小さな独立したサービスに分け、Web APIで連携させる構成。 | サービスごとに開発・更新・拡張ができる。反面、通信の増加や障害の切り分けが難しくなる。 |
| コンテナ（Docker／Kubernetes） | アプリと実行環境をまとめて動かす軽量な仮想化。Kubernetesは多数のコンテナを管理する仕組み。 | OSを共有するので、仮想マシンより起動が速く軽い。 |
| IaC | サーバやネットワークの構成をコード（設定ファイル）で記述し、自動で構築する手法。 | 同じ環境を何度でも正確に作れる。構成の変更履歴もコードとして管理できる。 |
| リファクタリング | 外部から見た動作（仕様）を変えずに、プログラムの内部構造を整理すること。 | 機能追加はしない。読みやすさ・保守しやすさを上げる。 |
| 中小受託取引適正化法（取適法） | 下請法を改正・改称した法律。シラバスVer.7.2で「下請法」から置き換わった。 | 委託する側（大企業など）が、受託する中小企業に不当な代金の減額や支払遅延をすることを禁じる。 |
