# 令和5年度秋期 午後 問5 ネットワーク／メールサーバの構築

## 1. 覚えるキーワード3つ
- DNSによるFQDNとIPアドレスの対応：メーラに設定する受信メールサーバは、DNSに登録されたFQDNとIPアドレスの対応で決まる
- OP25Bと中継サーバ：ISPが他ドメイン宛てのポート25の通信を止める対策。送信はISPのメールサーバを中継サーバにして行う
- ネットワーク部とホスト部：送信を許可するのは、端末のIPアドレスではなく、ネットワーク部で表すネットワークアドレス

## 2. 状況
- アパレル会社のL社が、新ブランドの広報のため、プロジェクトルームに広報サーバ(Web・SMTP・POP)を構築した。
- NAPTやDNSを設定してテストしたところ、POP3の受信エラーと、ISPのN社によるOP25Bで他ドメイン宛てのメール送信の失敗が起きた。
- 設問は、FW1のポート転送、DNSの設定、メーラの設定、OP25Bが防ぐ脅威、不正な送信を防ぐネットワークアドレスを問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| メーラの受信設定を直す | —（設問3(1)は正答率が低かった） | DNSに登録されたFQDNとIPアドレスの対応関係、DNSが使うポート番号から考える。受信メールサーバは192.168.1.10 | 受信メールサーバ |
| 他ドメイン宛てに送信できない | — | OP25Bは、広報サーバがスパムメールの送信に使われる脅威を減らす。広報サーバは、N社のメールサーバを中継サーバにして送信する設定にする | OP25B、中継サーバ |
| 不正な送信を防ぐ許可範囲 | 端末のIPアドレスを答える(設問4で散見) | 許可する範囲は、ネットワーク部で表すネットワークアドレス(192.168.0.0)。IPアドレスのネットワーク部とホスト部の考え方が基礎になる | ネットワークアドレス |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 a | FW1のポート転送の設定項目 | オ(宛先) |
| 1 b | HTTPSのポート番号 | エ(443) |
| 2 c | DNSに登録する名前 | serv(またはwww) |
| 2 d | DNSに登録するIPアドレス | w.x.y.z |
| 3(1) | メーラの設定の変更 | 受信メールサーバ → 192.168.1.10 |
| 3(2) | OP25Bで軽減できる脅威 | エ(スパムメールの送信に広報サーバが利用される) |
| 3(3) | 広報サーバに行う設定 | N社のメールサーバを中継サーバとしてメールを送信する設定 |
| 4 e | 送信を許可するネットワークアドレス | 192.168.0.0 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| FQDN | ホスト名とドメイン名をすべて書いた名前 |
| NAPT | アドレスとポート番号を変換し、1つのグローバルIPで複数の端末が通信できるようにする技術 |
| OP25B | ISPが、自社網の外へ出るポート25の通信を止める対策 |
| 中継サーバ | 送信メールを受け取り、宛先へ転送するサーバ |
| ネットワークアドレス | IPアドレスのネットワーク部だけを残し、ホスト部を0にしたアドレス |
| 踏み台 | 乗っ取られて、他への攻撃やスパム送信に悪用されるサーバ |

## 6. 思い出しクイズ
- Q1 OP25Bで軽減できる脅威は → スパムメールの送信に広報サーバが利用されること
- Q2 OP25Bのもとで、広報サーバがメールを送る設定は → N社のメールサーバを中継サーバにする
- Q3 送信を許可する範囲として答えるのは、端末のIPアドレスか → ネットワークアドレス(192.168.0.0)
- Q4 メーラの受信メールサーバに設定した内容は → 192.168.1.10
- Q5 HTTPSのポート番号は → 443

※採点講評：設問3(1)は正答率が低く、FQDNとIPアドレスの対応関係やDNSが使うポート番号が問われた。設問4も正答率が低く、端末のIPアドレスを答えた解答が散見された。
