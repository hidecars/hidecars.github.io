# 令和7年度秋期 午後 問11 システム監査／情報システムのアクセス管理状況の点検に関する監査

## 1. ひとことで
企業グループ全体のアクセス管理の点検について、点検が実際に機能しているかを確かめる監査手続を問う。

## 2. 状況
- 持株会社P社のシステム統括部が、グループ各社（Q社・R社・S社など）のアクセス管理を半年ごとに点検させている。
- P社内部監査部のシステム監査チームが、その点検の実効性を監査する。

![](img/2025r07a-sysaudit.svg)

## 3. 設問の狙いとキーワード

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 | 規程の管理策が適用できない場合の点検ポイントa | 代替の管理策の適用 |
| 2 | S社をサンプルに含める理由b | エ 点検（形骸化のおそれ） |
| 3(1) | 是正状況を確認する対象c | 委託先 |
| 3(2) | Q社システム部に働きかける組織d | P社システム統括部 |
| 3(3) | 働きかけの内容e | 是正を進めるよう指導、支援 |
| 4(1) | 管理表の更新で確認する記録f | 承認の記録 |
| 4(2) | インタビューで確かめる内容g | 更新の内容及び理由 |
| 5 | 照合する資料h・i | 各管理表／点検表 |

## 4. 解き方の型
- **型1 点検の「主体の役割」を確かめる**：不備を見つけるだけでなく、統括部門が是正を指導・支援しているかを見る。
- **型2 資料は「元」と「指示」を照合する**：対象を見直した結果（各管理表）と、実際の指示（点検表）を突き合わせる。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| 代替の管理策 | 規定どおりにできないときに代わりに講じる対策 |
| 形骸化 | 手続が形だけになり、効果がない状態 |
| サンプリング | 一部を選んで調べること |
| 是正 | 見つかった不備を直すこと |
| 承認の記録 | 責任者が確認・承認した証跡 |
| 照合 | 2つの資料を突き合わせて食い違いを確かめること |

## 6. 思い出しクイズ
- Q1 不備に対しP社システム統括部が行うべき働きかけは → 是正を進めるよう指導、支援する
- Q2 管理表の更新で確認する記録は → システム統括部長の承認の記録
- Q3 点検の指示を確かめるために照合する資料は → 各管理表と点検表
- Q4 規程の管理策が適用できない場合に点検するポイントは → 代替の管理策の適用
- Q5 管理表の更新でインタビューにより確かめる内容は → 更新の内容及び理由

※採点講評：設問3(3)は正答率が低く、設問5はやや低かった。
