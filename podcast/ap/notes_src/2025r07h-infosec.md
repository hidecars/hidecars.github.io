# 令和7年度春期 午後 問1 情報セキュリティ／サイバー攻撃への対策

## 1. ひとことで
業務提携先を起点としたサプライチェーン攻撃によるランサムウェア被害について、原因調査・侵入経路の特定・再発防止策を問う。

## 2. 状況
- C社（中古車販売会社）が、業務提携先P社の機器を足がかりに侵入され、各サーバのデータを暗号化された。
- NASのバックアップも暗号化データで上書きされ、古いログも上書きされて調査に支障が出た。
- 調査は外部のU社が担当した。

![](img/2025r07h-infosec.svg)

## 3. 設問の狙いとキーワード

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 | 証拠保全・調査・分析の名称 | デジタルフォレンジックス |
| 2 | PC-Pへの攻撃手法(a)と、PC-Rへのログイン方法(b) | a オ 辞書／b ウ RDP |
| 3 | 設定した項目と、それでも防げない理由 | ロックアウトのしきい値／同一IDで2回以上試行しない |
| 4(1) | 前日のバックアップから戻せない理由 | 暗号化されたデータで上書き |
| 4(2) | 過去の事象を調べられない理由 | 古い記録のログが上書きされる |
| 5 | バックアップを守るストレージ(c) | ア イミュータブル |

## 4. 解き方の型
- **型1 対策の前提条件を確かめる**：ロックアウトは「同じIDへの連続試行」にしか効かない。攻撃の仕組みと対策の効く条件を突き合わせる。
- **型2 「戻せない」「調べられない」は上書きを疑う**：バックアップやログが上書きされると復旧も調査もできない。書き換えできない保存方式で守る。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| デジタルフォレンジックス | 電磁的記録の証拠保全・調査・分析 |
| リバースブルートフォース攻撃 | パスワードを固定し、多数のIDで試す攻撃 |
| 辞書攻撃 | よく使われる語を順に試してパスワードを当てる攻撃 |
| RDP | 別のPCの画面を遠隔操作するプロトコル |
| イミュータブル | 書き込んだデータを変更できない性質 |
| サプライチェーン攻撃 | 取引先など弱い所を起点に標的へ侵入する攻撃 |

## 6. 思い出しクイズ
- Q1 ロックアウト設定がリバースブルートフォース攻撃に効かない理由は → 同一IDで2回以上ログインを試行しないから
- Q2 前日のバックアップから復旧できなかった理由は → 暗号化されたデータで上書きされていたから
- Q3 バックアップの書き換えを防ぐストレージの性質は → イミュータブル
- Q4 証拠保全・調査・分析を行う手法の名称は → デジタルフォレンジックス
- Q5 PC-RからPC-Sへのログインに使われた攻撃は → リバースブルートフォース攻撃

※採点講評：設問3の「理由」と設問5は正答率が低かった。
