# 令和7年度春期 午後 問1 情報セキュリティ／サイバー攻撃への対策

## 1. 覚えるキーワード3つ
- リバースブルートフォース攻撃：パスワードを固定し、IDを次々に変えてログインを試す攻撃
- イミュータブル（ストレージ）：書き込んだデータを変更・上書き・削除できない性質
- デジタルフォレンジックス：電磁的記録の証拠保全・調査・分析を行い、原因を究明する手順

## 2. 状況
- C社（中古車販売会社）が、業務提携先P社の自宅PCとVPNルータの脆弱性を足がかりに侵入された。
- 同じ認証情報の使い回しでPC-Rへ入られ、リバースブルートフォース攻撃でPC-Sとサーバを突破された。
- ランサムウェアでデータが暗号化され、バックアップも暗号化データで上書きされた。古いログも上書きされた。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 対策したのにログイン攻撃を防げない | — | ロックアウトは同じIDへの連続試行にしか効かない。攻撃の仕組みと対策の効く条件を突き合わせる | 同一のIDで2回以上ログイン試行しない |
| バックアップから戻せない | — | 上書きされない保存方式で守る。書き込み後に変更できないストレージ（イミュータブル）にする | 暗号化されたデータで上書き |
| 過去の事象を調べられない | — | ログは端末内に置かず、ログサーバへ集めて長く保管する | 古い記録のログが上書きされる |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1 | 証拠保全・調査・分析の名称 | デジタルフォレンジックス |
| 2 | PC-Pへの攻撃手法(a)と、PC-Rへのログイン方法(b) | a オ 辞書／b ウ RDP |
| 3 | 設定した項目と、それでも防げない理由 | ロックアウトのしきい値／同一IDで2回以上試行しない |
| 4(1) | 前日のバックアップに起きていたおそれのある事象 | 暗号化されたデータで上書き |
| 4(2) | 過去の事象を調べられない理由 | 古い記録のログが上書きされる |
| 5 | バックアップを守るストレージ(c) | ア イミュータブル |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| デジタルフォレンジックス | 電磁的記録の証拠保全・調査・分析 |
| リバースブルートフォース攻撃 | パスワードを固定し、多数のIDで試す攻撃 |
| 辞書攻撃 | よく使われる語を順に試してパスワードを当てる攻撃 |
| RDP | 別のPCの画面を遠隔操作するプロトコル（TCP:3389） |
| イミュータブル | 書き込んだデータを変更できない性質（WORM） |
| ステートフルパケットインスペクション | 通信の状態を見て、対応する応答だけを通すFWの制御方式 |

## 6. 思い出しクイズ
- Q1 証拠保全・調査・分析を行う一連の手順は → デジタルフォレンジックス
- Q2 パスワードを固定し、IDを変えて試す攻撃は → リバースブルートフォース攻撃
- Q3 その攻撃にロックアウトが効かない理由は → 同一のIDで2回以上ログイン試行しないから
- Q4 書き込んだデータを変更できないストレージの性質は → イミュータブル
- Q5 ログの保存容量が上限に達して調べられなくなる原因は → 古い記録のログが上書きされるから

※採点講評：設問3の「理由」と設問5は正答率が低かった。
