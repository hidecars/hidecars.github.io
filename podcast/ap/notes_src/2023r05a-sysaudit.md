# 令和5年度秋期 午後 問11 システム監査／情報システムに係るコンティンジェンシー計画の実効性の監査

## 1. 覚えるキーワード3つ
- コンティンジェンシー計画の実効性：計画を作っただけでなく、障害時に実際に動くことを確かめる
- 定期的な訓練：発動時の手順と現在の訓練内容を比べ、不足している訓練を見つける
- 環境変化に応じたリスクの再評価：システム環境の変化に合わせてリスクを見直し、計画の内容を更新する

## 2. 状況
- 通信販売事業者のZ社で、東センターの障害時に西センターへウォームスタンバイで切り替えるコンティンジェンシー計画(CP)がある。
- 事業拡大に伴うリスクの増大を受け、内部監査室がCPの実効性を監査する。
- 設問は、監査の背景から識別するリスク、サーバの処理能力、ネットワーク切替えを含む環境設定、訓練内容、障害時の影響を問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 監査の背景からリスクを識別する | —（設問2は正答率がやや低かった） | 「今回の監査の背景を踏まえると」という前提から、監査に至った経緯の記載を読み取る。追加で考えるのは、システム障害の影響が拡大するリスクと、サイバー攻撃の脅威が増大するリスク | 監査の背景 |
| 訓練が足りているか確かめる | 机上では訓練できない内容を答える(設問4で散見) | CP発動時の手順と、現在の訓練内容を比べる。不足は、ネットワークの切替えを含む必要な環境設定 | 発動時の手順、訓練内容 |
| 切替え後の運用を確かめる | — | 切替え先のサーバの処理能力を増強しておく。障害時は、社内の業務とコミュニケーションに支障が出る | サーバの処理能力 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| コンティンジェンシー計画 | 障害や災害が起きたときの、対応手順を定めた計画 |
| ウォームスタンバイ | 待機系を稼働状態に近くしておき、障害時に素早く切り替える方式 |
| 目標復旧時間 | 障害から復旧するまでの目標とする時間 |
| CP発動基準 | コンティンジェンシー計画を発動する条件 |
| 内部監査 | 組織内の監査部門が行う監査 |
| 監査手続 | 監査の要点を確かめるための具体的な手順 |

## 6. 思い出しクイズ
- Q1 計画策定後に定期的に行うべきことは → 訓練
- Q2 監査の背景から、追加で考えるリスクの1つは → サイバー攻撃の脅威が増大するリスク
- Q3 もう1つのリスクは → システム障害発生時の影響が拡大するリスク
- Q4 訓練に不足している内容は → ネットワークの切替えを含む必要な環境設定
- Q5 CPを見直すきっかけになるのは → システム環境などの変化

※採点講評：設問2は正答率がやや低く、監査を実施することになった経緯の記載を読み取ることが求められた。設問4も正答率がやや低く、机上では訓練できない内容を答えた解答が散見された。
