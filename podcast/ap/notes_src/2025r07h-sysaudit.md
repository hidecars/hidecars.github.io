# 令和7年度春期 午後 問11 システム監査／勤務管理に関連するシステムの監査

## 1. ひとことで
勤務管理に関連するシステムの運用・保守段階で、リスクに対するコントロールを監査でどう確かめるかを問う。

## 2. 状況
- 小売業のW社。内部監査部のシステム監査チームが、勤務管理システムと関連システムを監査する。テレワーク対応などの変更がある。

![](img/2025r07h-sysaudit.svg)

## 3. 設問の狙いとキーワード

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | 誤登録が起きる作業 | 手作業 |
| 1(2) | 誤登録リスクへの確認点 | 入力コントロール |
| 2(1) | テレワーク対応で確認する対象 | 勤務形態 |
| 2(2) | 時差確認メッセージの表示条件 | 一定の組合せ |
| 3(1) | 連携元のシステム | 人事管理 |
| 3(2) | リスクの要因 | 従業員の職種の誤登録 |
| 3(3) | 確認する基準の時点 | X年3月末日 |

## 4. 解き方の型
- **型1 リスク→コントロールの順に考える**：「誤登録のリスク」があれば「入力コントロールが組み込まれているか」を確かめる。
- **型2 変更点は条件設定を見る**：テレワーク対応のような業務ルールの変更では、判定条件（勤務形態の組合せ）が想定どおりかを確かめる。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| 入力コントロール | 入力時の誤りや不正を防ぐ仕組み（補足） |
| 監査手続 | 監査で証拠を集めるための具体的な確認方法（補足） |
| 勤務形態 | 標準勤務・テレワークなど働き方の区分（補足） |
| システム連携 | 他システムのデータを受け渡して使うこと（補足） |
| 運用・保守段階 | 稼働後に運用・改修していく段階 |

## 6. 思い出しクイズ
- Q1 標準勤務時間の誤登録リスクに対し、監査で確認する仕組みは → 入力コントロール
- Q2 時差確認メッセージの表示条件で確認することは → 勤務形態の一定の組合せを想定しているか
- Q3 設問3(2)で挙げるリスクの要因は → 従業員の職種の誤登録（人事管理システム側）
- Q4 標準勤務時間の誤登録が起きる原因となる作業は → 手作業
- Q5 職種などの属性を勤務管理システムへ連携する元のシステムは → 人事管理システム

※採点講評：設問1(2)と設問2は正答率がやや低い。
