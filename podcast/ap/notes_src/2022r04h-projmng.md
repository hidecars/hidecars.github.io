# 令和4年度春期 午後 問9 プロジェクトマネジメント／販売システムの再構築プロジェクトにおける調達とリスク

## 1. 覚えるキーワード3つ
- 請負契約と準委任契約：請負は成果物の完成責任を問える。派遣労働者を発注者が選定・指揮すると、労働者派遣法に抵触するおそれがある
- 要求事項の提出期限の合意：プロトタイピングでは要求が膨らみやすい。提出時期と件数の上限を、利用部門と合意する
- 中間成果物の品質レビュー：請負では完成まで品質を確認できない。契約に条項を足し、作業の途中で品質レビューを行う

## 2. 状況
- 衣料品製造・ネット販売のD社が、販売システムを再構築する。営業部門と、システム部のE課長、F君が関わり、外部委託先のZ社がいる。
- 要件定義では、労働者派遣法に抵触する条件の是正と、営業部門との認識の共有が必要になった。
- Z社との契約(準委任・請負)の選び方と、仕様の手戻り、製造品質の不良、動作確認するブラウザの制限という3つのリスクへの対応が課題。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 外部委託の契約形態を選ぶ | — | 合意した外部設計に基づく製造は、請負ならZ社に完成責任を問える。派遣労働者をF君が選定する条件は、労働者派遣法に抵触する | 完成責任、検収、著作権 |
| 要求が膨らむ(プロトタイピング) | —（設問3(1)は正答率がやや低かった） | 要求事項の提出時期と、対応件数の上限を利用部門と合意する。限られた期間で、要求を正確に最大限取り込む | 提出期限 |
| 製造品質が不安 | —（設問3(2)は正答率が低かった） | 請負では、契約に条項がなければ、完成まで品質を確認する権利がない。受注者と合意のうえ契約に条項を足し、作業の途中で品質レビューを行う | 品質レビュー |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| 請負契約 | 成果物の完成を約束する契約 |
| 準委任契約 | 成果物ではなく、業務の遂行を委託する契約 |
| 労働者派遣法 | 派遣労働者の就業条件などを定めた法律 |
| ユースケース図 | システムの利用者と機能の関係を表す図 |
| プロトタイピング | 試作品を見せて、要求を確かめながら進める手法 |
| 検収 | 納品された成果物が要件を満たすか確認して受け入れること |

## 6. 思い出しクイズ
- Q1 成果物の完成責任をZ社に問えるのは、どの契約か → 請負契約
- Q2 プロトタイピングで要求が膨らむとき、利用部門と合意するのは → 要求事項の提出期限(と件数の上限)
- Q3 請負で品質を確認するため、作業の途中で行うことは → 品質レビュー
- Q4 システムの利用者と機能の関係を表す図は → ユースケース図
- Q5 サービス開始前に公表する、ブラウザの情報は → 上位2種類以外のブラウザでは問題が生じる場合があること

※採点講評：設問3(1)は正答率がやや低く、要求事項の提出時期や件数の上限を利用部門と合意する対応が問われた。設問3(2)は正答率が低く、請負では完成まで品質を確認できないことの理解が求められた。
