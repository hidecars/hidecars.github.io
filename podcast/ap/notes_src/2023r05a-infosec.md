# 令和5年度秋期 午後 問1 情報セキュリティ／電子メールのセキュリティ対策

## 1. 覚えるキーワード3つ
- PPAP方式の問題点：本文メールを誤送信すると、パスワードも同じ相手に届く。パスワードは別の手段で伝える
- S/MIME：電子署名で改ざんを検知し、暗号化で盗聴を防ぐ。どの手順でどの鍵を使うかを押さえる
- 共通鍵暗号と公開鍵暗号の使い分け：本文の暗号化・復号には、処理が速い共通鍵暗号を使う

## 2. 状況
- 卸売会社のK社は、過去の誤送信事故のあと、ZIP添付とパスワードの別メール送信(PPAP方式)を導入した。
- 政府の廃止方針や、宛先を確認しない送信、同じ経路でパスワードを送ることによる盗聴リスクなどの問題が表に出た。
- 一時的な運用改善を行いつつ、S/MIMEの導入で暗号化と改ざん防止を実現する。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| PPAP | パスワード付きZIPを添付し、パスワードを別メールで送る方式 |
| S/MIME | メールに電子署名と暗号化を付ける方式 |
| 電子署名 | 送信者の秘密鍵で作り、改ざんと本人性を確かめる仕組み |
| 共通鍵暗号 | 暗号化と復号に同じ鍵を使う方式。処理が速い |
| 公開鍵暗号 | 公開鍵と秘密鍵の対を使う方式。処理が複雑 |
| CA | 認証局。電子証明書を発行する機関 |

## 6. 思い出しクイズ
- Q1 PPAPで本文メールを誤送信すると、何も一緒に届くか → パスワード(DPW)
- Q2 パスワードの盗聴リスクを下げる運用改善は → 電話や携帯メールなど別の手段で伝える
- Q3 電子署名を作るときに使う鍵は → 送信者の秘密鍵
- Q4 共通鍵暗号を使う理由は → 暗号化と復号の処理速度が速い
- Q5 証明書の検証に必要な鍵は → CAの公開鍵

※採点講評：設問2(2)は正答率が平均的で、どの手順でどの鍵が使われるかまでの理解が求められた。設問2(3)は正答率が低かった。設問3は正答率がやや高かった。
