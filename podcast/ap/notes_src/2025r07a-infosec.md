# 令和7年度秋期 午後 問1 情報セキュリティ／企業グループのセキュリティ対策

## 1. ひとことで
ビジネスとソフトウェアの2つのサプライチェーン攻撃について、技術的な対処と情報管理の基本原則を問う。

## 2. 状況
- 産業機械メーカーZ社の情報システム部（B部長・T主任）が、子会社を含むグループ全体の対策を検討する。
- 共通業務システムは内部ネットワークのセグメントGにあり、子会社はインターネットVPN経由で使う。

| 1 a | 空欄（解答群から選択） | ク 境界防御 |

## 4. 解き方の型
- **型1 内部不正は「心理」でも防ぐ**：検知だけでなく、不正のトライアングル（動機・機会・正当化）を減らす。見つかりやすさは心理的な障壁になる。
- **型2 ソフトウェアは「中身の一覧」で守る**：部品構成（SBOM）がないと、脆弱性が出たときに影響範囲をすぐ判断できない。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| サプライチェーン攻撃 | 取引先や部品など弱い所を起点に標的へ侵入する攻撃 |
| 境界防御 | 内と外の境目で守る考え方 |
| need-to-know | 業務に必要な人にだけ情報を渡す原則 |
| SIEM | 各種ログを集めて相関分析し、異常を見つける仕組み |
| SBOM | ソフトウェアを構成する部品の一覧 |
| 不正のトライアングル | 動機・機会・正当化がそろうと不正が起きるという考え方 |

## 6. 思い出しクイズ
- Q1 ソフトウェアの部品構成を一覧にしたものは → SBOM
- Q2 内部不正の抑止で、技術的対策のほかに考えるべき面は → 心理的な面（発覚リスクを高く感じさせる）
- Q3 SBOMがないと何が困るか → 脆弱性発見時に影響範囲を迅速に判断できない
- Q4 各種ログを集めて相関分析する仕組みは → SIEM
- Q5 業務に必要な人にだけ情報を渡す原則は → need-to-know

※採点講評：設問3(2)は正答率がやや低かった。
