# 令和5年度春期 午後 問1 情報セキュリティ／マルウェア対策

## 1. 覚えるキーワード3つ
- EDR：PC上の不審な挙動を監視して、検知・対応につなげる仕組み
- インシデント対応体制・手順の明文化：発生したときの体制(CSIRT)と手順を、事前に決めて文書にしておく
- バックアップの切り離し保管：ランサムウェアの被害が及ばないよう、バックアップ媒体はPCから切り離して保管する

## 2. 状況
- 旅行代理店のR社で、従業員のPC(PC-S)がランサムウェアに感染し、文書ファイルが暗号化された。
- セキュリティ支援会社のZ社の評価で、検知対策の不足、インシデント対応体制・手順の未整備、社員教育の不足が判明した。
- 設問は、一次対応、攻撃の段階の特定、体制・技術面の改善、社員教育・訓練を順に問う。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| PC上の不審な挙動を見つけたい | —（設問2(2)は正答率が低かった） | 振る舞いを監視するEDRを使う。仕組みと効果まで理解しておく | 不審な挙動の監視 |
| 感染や攻撃が起きたときの動き方 | — | 感染したPCはまずネットワークから切り離す。対応体制と手順は、あらかじめ明文化して訓練しておく | 対応体制、手順 |
| バックアップを守りたい | —（設問4(2)は正答率が平均的） | ランサムウェアは、PCからアクセスできるファイルサーバや記録媒体にも被害を広げる。バックアップ媒体はPCから切り離して保管する | 記録媒体、バックアップ |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | 感染したPCに直ちに行う一次対応 | ウ(ネットワークからの切り離し) |
| 1(2) a | 完了した攻撃の段階 | 5(インストール) |
| 2(1) | 「対応手順の未整備」への改善策 | 5(対応体制・手順の明文化) |
| 2(2) | PC上の不審な挙動の監視の仕組み | イ(EDR) |
| 3(1) | インシデント対応を行う組織 | イ(CSIRT) |
| 3(2) b〜d | 課題に対応する取組み | b・cは3と6(順不同)、dは5 |
| 3(3) | 過去事例の調査で見る内容 | ア(攻撃手法)、ウ(被害を受けた機器の種類) |
| 4(1) | 全従業員の訓練で行う対応の段階 | ア(検知／通報) |
| 4(2) | バックアップ媒体の保管 | PCから切り離して保管する |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| EDR | 端末の不審な挙動を監視し、検知・対応を支援する仕組み |
| CSIRT | セキュリティ事故に対応する組織・チーム |
| ランサムウェア | ファイルを暗号化して身代金を要求するマルウェア |
| サイバーキルチェーン | 攻撃を段階に分けて捉える考え方。5番目がインストール |
| インシデントハンドリング | 検知から復旧、再発防止までの一連の対応 |
| 標的型攻撃メール | 特定の組織を狙って送られる、業務を装ったメール |

## 6. 思い出しクイズ
- Q1 PC上の不審な挙動を監視する仕組みは → EDR
- Q2 感染したPCに、まず行う一次対応は → ネットワークから切り離す
- Q3 インシデント対応を行う組織の略称は → CSIRT
- Q4 バックアップ媒体の適切な保管方法は → PCから切り離して保管する
- Q5 「対応手順の未整備」への改善策は → 対応体制・手順を検討して明文化する

※採点講評：設問2(2)は正答率が低く、EDRの仕組みと効果の理解が求められた。設問4(2)は正答率が平均的で、バックアップをランサムウェアから守る方策の理解が問われた。
