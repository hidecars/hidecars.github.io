# 令和7年度春期 午後 問9 プロジェクトマネジメント／CCPMを用いたプロジェクトのスケジュール管理

## 1. ひとことで
パーキンソンの法則への対策として、CCPMのバッファ統合と要員シフトで納期遅延を抑える考え方を問う。

## 2. 状況
- 小売業を営む会社の販売管理システム再構築。加重総和法で提案を選び、CCPMでスケジュールを作成・管理する。

```
販売管理システム再構築
 ├ 提案評価：加重総和法（費用・要求充足度を重視）
 └ スケジュール：CCPM
     ├ 各アクティビティ：個別バッファを除く
     └ 全体：バッファを統合して管理＋遅延時は要員シフト
```

## 3. 設問の狙いとキーワード

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | 評価結果がそうなった理由 | 費用・要求充足度を重要視 |
| 1(2) | 選ぶべき提案 | K |
| 2(1) | バッファ除去後の日数 | 41 |
| 2(2) | バッファを統合する効果 | バッファを不必要に消費しなくなる |
| 2(3) | 状態の判定 | c エ、d イ |
| 3(1) | 指標値の読み取り | 1 |
| 3(2) | 遅延しそうなときの対策 | J3チームの要員を D2 に投入（要員シフト） |

## 4. 解き方の型
- **型1 条件を漏れなく拾って計算・判断する**：重み、バッファの扱いなど本文のルールを抜き出してから計算する。
- **型2 手法の本質で対策を書く**：CCPMは全体最適の協力体制。遅延対策は「延期」でなく、余裕のあるチームから要員を移す。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| パーキンソンの法則 | 余裕を与えると、その期限いっぱいまで作業してしまう傾向 |
| CCPM | 個別バッファを除き、統合バッファで管理する手法 |
| バッファ | 遅れを吸収するための予備の時間 |
| 加重総和法 | 評価点×重みの合計で比較する評価方法 |
| 要員シフト | 遅れそうな作業へ他チームの要員を移すこと |
| クリティカルチェーン | 資源の制約も考えた最長の作業の連なり（補足） |

## 6. 1分セルフチェック
- Q1 CCPMが対策とする法則は → パーキンソンの法則
- Q2 バッファを統合する効果は → 作業者がバッファを不必要に消費しなくなる
- Q3 遅れそうなとき、延期以外の対策は → 他チーム（J3）の要員を遅延箇所（D2）へ投入する

※採点講評：設問3(2)は「スケジュールの延期」という解答が散見された。
