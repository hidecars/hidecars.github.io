# 令和7年度春期 午後 問9 プロジェクトマネジメント／CCPMを用いたプロジェクトのスケジュール管理

## 1. 覚えるキーワード3つ
- パーキンソンの法則：余裕を与えると、その期限いっぱいまで作業してしまう傾向
- バッファの統合：作業ごとの余裕を外し、まとめて管理して遅れを吸収する
- 要員シフト：遅れそうな作業へ、余裕のあるチームの要員を移すこと

## 2. 状況
- 小売業を営む会社の販売管理システム再構築。加重総和法で提案を選び、CCPMでスケジュールを作成・管理する。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| 作業者が余裕を使い切ってしまう | — | 個別の余裕を外してバッファを統合すると、余裕を不必要に消費しなくなる | バッファ、パーキンソンの法則 |
| 提案を比較して選ぶ | — | 評価点に重みを掛けて合計する（加重総和法）。重みが大きい観点（費用・要求充足度）の影響を読み取る | 重み、評価点 |
| 作業が遅れそうだ | スケジュールの延期 | 延期ではなく、余裕のあるチームから遅れる作業へ要員を移す | J3チーム、D2 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| パーキンソンの法則 | 余裕を与えると、その期限いっぱいまで作業してしまう傾向 |
| CCPM | 個別バッファを除き、統合バッファで管理する手法 |
| バッファ | 遅れを吸収するための予備の時間 |
| 加重総和法 | 評価点×重みの合計で比較する評価方法 |
| 要員シフト | 遅れそうな作業へ他チームの要員を移すこと |
| クリティカルチェーン | 資源の制約も考えた最長の作業の連なり（補足） |

## 6. 思い出しクイズ
- Q1 CCPMが対策とする法則は → パーキンソンの法則
- Q2 バッファを統合する効果は → 作業者がバッファを不必要に消費しなくなる
- Q3 遅れそうなとき、延期以外の対策は → 他チーム（J3）の要員を遅延箇所（D2）へ投入する
- Q4 加重総和法とは → 評価点数に重みを掛けた値の合計で比べる方法
- Q5 CCPMで余裕を各作業から外して統合する理由は → 作業者が余裕を不必要に消費しなくなるから
