# 令和4年度春期 午後 問5 ネットワーク／ネットワークの構成変更

## 1. 覚えるキーワード3つ
- トンネリングと送信元IPアドレス：IPsecルータ間でトンネリングしても、パケットの送信元IPアドレスは変わらない
- 経路表のネクストホップ：宛先ごとの転送先を経路表で決める。q-SaaS宛ては、IPsecルータ1をネクストホップにする
- FWへの通信負荷の集中を避ける：SaaS宛ての通信をプロキシやFWに通さず、直接つなぐ経路にする

## 2. 状況
- 中堅商社のP社は、ISサーバを廃止してGサービス(q-SaaS)を導入した。その後、時間帯によって通信速度が落ちるようになった。
- 原因は、FWのセッション数が増えて、負荷が集中したことだった。
- q-SaaS宛ての通信を、プロキシサーバやFWを通らずに直接アクセスさせる経路へ変更し、負荷を減らす。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| NPC | ネットワークに接続するPC |
| プロキシサーバ | Webアクセスを代理で行うサーバ |
| IPsecルータ | IPsecで拠点間に安全なトンネルをつくるルータ |
| ネクストホップ | 経路表で示す、次に転送する先の機器 |
| SaaS | ソフトウェアをインターネット経由で利用するサービス |
| FQDN | ホスト名とドメイン名をすべて書いた名前 |

## 6. 思い出しクイズ
- Q1 IPsecルータ間でトンネリングしても変わらないものは → 送信元IPアドレス
- Q2 営業所のPCの通信の送信元として答えるのは → 営業所のNPC
- Q3 q-SaaS宛ての通信のネクストホップは → IPsecルータ1
- Q4 FWの負荷集中を避けるため、SaaS宛ての通信をどうするか → プロキシやFWを通さずに直接つなぐ
- Q5 設問2で、削除するFQDNをもつ機器は → ISサーバ

※採点講評：設問1(1)の送信元は正答率がやや低く、IPsecルータと答える解答が散見された。設問3(1)は正答率がやや低く、設問3(2)のeは正答率が低かった。
