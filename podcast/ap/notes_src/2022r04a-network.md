# 令和4年度秋期 午後 問5 ネットワーク／テレワーク環境への移行

## 1. 覚えるキーワード3つ
- 証明書とワンタイムパスワード：リモートアクセスの認証では、2種類の証明書と、一定時間だけ有効なワンタイムパスワードを使う
- 通信帯域の計算：Web会議サービスの通信が増えると、本社の回線帯域が足りなくなる。1人当たりの帯域と同時利用の割合で見積もる
- UTMで許可する接続先：営業所のUTMでは、Web会議サービスと本社VPNサーバへの接続だけを許可し、通信量を抑える

## 2. 状況
- HP制作会社のW社は、回線の増強工事に2か月かかるなか、テレワークへの移行を進めた。
- Web会議サービスの通信が集中して回線帯域が足りなくなり、応答遅延や映像・音声の中断が頻発した。
- 営業所のUTMを使ったアクセス設定などで通信量を抑え、トラブルに対処する。

## 3. 分野の核心

| 場面 | ありがちな誤答 | 正解の考え方 | 根拠になる本文の言葉 |
|---|---|---|---|
| リモートアクセスの認証 | —（設問2(1)は正答率が低かった） | 第一段階の認証の流れから、2種類の証明書が必要なサーバを読み取る。Webサーバと本社VPNサーバ。ワンタイムパスワードで認証する | 証明書、ワンタイムパスワード |
| 回線が足りない | —（設問3(1)(2)は正答率がやや高かった） | Web会議サービスの通信がすべて本社のインターネット接続回線を通ることが原因。1人当たりの帯域を、同時利用の割合で見積もる | 本社のインターネット接続回線、帯域 |
| 営業所のUTMで通信を絞る | — | Web会議サービスと本社VPNサーバに限って許可する | UTM、アクセス許可 |

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| UTM | ファイアウォールなど複数のセキュリティ機能をまとめた機器 |
| VPN | 公衆回線上に、安全な専用回線のような通信をつくる技術 |
| ワンタイムパスワード | 一度、一定時間だけ有効なパスワード |
| TLS | 通信を暗号化するプロトコル |
| HTTPS | TLSでHTTP通信を暗号化したプロトコル |
| IPsec | IPのレベルで通信を暗号化する仕組み |

## 6. 思い出しクイズ
- Q1 一定時間だけ有効な認証用パスワードは → ワンタイムパスワード
- Q2 証明書が必要なサーバは → Webサーバと本社VPNサーバ
- Q3 内部PCのログインの認証先は → 認証サーバ
- Q4 通信量が増えた要因は → Web会議サービスのすべての通信が本社のインターネット接続回線を通ること
- Q5 UTMが許可する接続先は → Web会議サービスと本社VPNサーバ

※採点講評：設問2(1)は正答率が低く、第一段階の認証の流れから証明書を使うサーバを読み取ることが求められた。設問3(1)(2)は正答率がやや高く、トラブルの要因や帯域の計算はよく理解されていた。
