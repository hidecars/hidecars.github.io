# 令和4年度春期 午後 問1 情報セキュリティ／通信販売サイトのセキュリティインシデント対応

## 1. 覚えるキーワード3つ
- 不要なサービスの停止：サーバで不要なサービスが動いていると悪用される。最低限必要なものを除いて停止する
- ゼロデイ攻撃への暫定対策：修正プログラムが公開される前の脆弱性を突かれる攻撃。回避策を調べて暫定対策を判断する
- SIEM：ログを統合管理し、相関分析をリアルタイムに行って、インシデントを早く見つける仕組み

## 2. 状況
- 文房具・オフィス家具製造販売のR社の通信販売サイトで、CMSの脆弱性を突かれ、サイトの改ざんと不適切なサイトへの誘導が起きた。
- WAFの更新で過検知が出てシグネチャの更新を止めていたこと、サイトを閉鎖するルールがないこと、改ざんの検知が遅れたこと、ログの相関分析に時間がかかったことが課題になった。
- 再発防止策の立案と、攻撃を受けたあとの対処を問う。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| ゼロデイ攻撃 | 修正プログラムの公開前の脆弱性を突く攻撃 |
| WAF | Webアプリケーションへの攻撃を防ぐ装置・仕組み |
| 過検知 | 正常な通信を攻撃と誤って検知すること |
| SIEM | ログを集めて相関分析し、異常を検知する仕組み |
| CMS | Webサイトのコンテンツを管理するソフトウェア |
| インシデント対応チーム | セキュリティ事故に対応する組織 |

## 6. 思い出しクイズ
- Q1 サーバで不要なサービスはどうするか → 最低限必要なものを除いて停止する
- Q2 修正プログラムの公開前の脆弱性を突く攻撃は → ゼロデイ攻撃
- Q3 WAFのシグネチャ更新を止めた原因は → 過検知
- Q4 ログを統合管理し、相関分析をリアルタイムに行う仕組みは → SIEM
- Q5 インシデントに対応する組織は → インシデント対応チーム

※採点講評：設問1は正答率がやや低く、不要なサービスの停止の重要性が問われた。設問4(5)は正答率が低く、SIEMの役割の理解が求められた。
