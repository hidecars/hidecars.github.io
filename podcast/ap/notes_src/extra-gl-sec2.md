# 用語集・情報セキュリティ②／情報セキュリティ用語② 部品表・バックアップ・調査・設定

## 1. 覚えるキーワード3つ
- SBOM：部品と版数の一覧
- イミュータブルバックアップ：変更できない保存
- リバースブルートフォース攻撃：パスワード固定でIDを順に試す

## 2. 状況
- シラバス強化用語集（2026/10/30版）のうち「情報セキュリティ②」の6語を扱う。
- 令和8年度からCBT方式（科目A=午前、科目B=午後）。シラバスはVer.7.2。
- 使い方：まず「ひとこと」を声に出して読み、「午後での問われ方」を確認する。

## 3. 分野の核心

| 用語 | ひとこと | ポイント |
|---|---|---|
| SBOM | ソフトウェアを構成するOSSなどの部品と版数の一覧。 | 脆弱性が公表されたとき、影響を受けるソフトウェアをすぐ特定できる。 |
| イミュータブルバックアップ | 一度書き込んだら、一定期間は変更・削除できない形で保存するバックアップ。 | ランサムウェアはバックアップも暗号化・上書きする。書き換えできなければ復旧に使える。 |
| デジタルフォレンジックス | 電磁的記録の証拠保全・調査・分析を行う技術や手続。 | 調査前に証拠を保全（複製・ハッシュ値で改ざん確認）してから分析する順番が重要。 |
| リバースブルートフォース攻撃 | パスワードを1つに固定し、多数のIDに順に試す攻撃。 | 同じIDに何度も試さないので、ロックアウト（一定回数失敗で停止）が効かない。 |
| ASM | インターネットから見える自社のIT資産（攻撃対象領域）を洗い出し、継続的に管理すること。 | 管理されていない公開サーバや古い機器は攻撃の入口になる。まず「把握」から始める。 |
| CSPM | クラウドの設定を継続的に点検し、設定ミスやポリシー違反を検出する仕組み。 | クラウドの情報漏えいは設定ミスが原因になりやすい。CSPMは「設定」を見る。 |

## 4. 解答キーワード一覧

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| SBOM | 「SBOMがないと何が困るか」 → 脆弱性発見時に影響範囲を迅速に判断できない（R7秋 午後問1の解答例）。 | R7秋 午後問1、R7春 午前問40、R6秋 午前問43 |
| イミュータブルバックアップ | 「前日のバックアップから復旧できなかった理由」 → 暗号化されたデータで上書きされていた（R7春午後問1）。 | R7春 午後問1（設問5 解答：イミュータブル） |
| デジタルフォレンジックス | 名称をそのまま答える空欄補充が多い。「ログが上書きされて調査できない」もセットで出る。 | R7春 午後問1（設問1）、R7秋 午前問44、H27秋 午前問43 |
| リバースブルートフォース攻撃 | 「ロックアウトで防げない理由」 → 同一のIDで2回以上ログインを試行しないから（R7春 午後問1）。 | R7春 午後問1（設問3 正答率が低かった） |
| ASM | 「把握していない機器が侵入口になった」事例の対策として書ける。 | 今回の資料内では出題を確認できていない |
| CSPM | クラウド利用時の「設定不備による公開」の対策として選択肢に出る。 | R7秋 午前問42ネットワーク |

## 6. 思い出しクイズ
- Q1 SBOMとは → ソフトウェアを構成するOSSなどの部品と版数の一覧。
- Q2 イミュータブルバックアップとは → 一度書き込んだら、一定期間は変更・削除できない形で保存するバックアップ。
- Q3 デジタルフォレンジックスとは → 電磁的記録の証拠保全・調査・分析を行う技術や手続。
