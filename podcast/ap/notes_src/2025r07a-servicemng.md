# 令和7年度秋期 午後 問10 サービスマネジメント／社内手続を扱うサービスデスク

## 1. ひとことで
社内向けサービスデスクとFAQ運用の課題を題材に、SPOC・SLA・エスカレーション・自己解決率の改善を問う。

## 2. 状況
- 通信会社J社の情報システム部運用課が、社内手続の問合せを受けるサービスデスク（SD）を運営する。
- ポータル（Pサービス）のセルフヘルプでFAQを検索でき、その記録がFログに残る。

![](img/2025r07a-servicemng.svg)

## 3. 設問の狙いとキーワード

| 設問 | 問われていること | 決め手のキーワード |
|---|---|---|
| 1(1) | 窓口の一本化を表す機能名a | SPOC |
| 2(1) | 利用可能時間の割合を表すSLA項目b | 可用性（稼働率） |
| 2(2) | 1か月（22営業日）の許容停止時間c | 158（分） |
| 3(1) | 問合せの分類で割り当てる属性d | 優先度 |
| 3(2) | 手順書で答えられないときの手続e | エスカレーション |
| 4(1) | FAQ登録の優先度を付ける分析方法 | 疑問が解決しなかった問合せの発生頻度 |
| 4(2) | 突き合わせるデータ項目f・g | 入力されたキーワード／問合せキーワード |

## 4. 解き方の型
- **型1 計算は本文の数字を拾い切る**：営業日数・提供時間・目標値を本文から読み取ってから計算する。
- **型2 データ項目は本文にあるものだけ使う**：Fログや問合せ管理DBにある項目名で答える。本文にない項目を書くと誤答になる。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| SPOC | 問合せ窓口を一つにまとめること |
| SLA | 提供者と利用者が合意したサービスレベル |
| 可用性 | 使える時間の割合 |
| エスカレーション | 対応できない案件を上位や専門部署へ引き継ぐこと |
| FAQ | よくある質問と回答の集まり |
| 自己解決率 | 利用者が自分で解決できた割合 |

## 6. 思い出しクイズ
- Q1 問合せ窓口を一本化する考え方は → SPOC
- Q2 SDが手順書で答えられないときに行う手続は → エスカレーション
- Q3 FAQに登録すべき問合せを選ぶ分析は → 疑問が解決しなかった問合せの発生頻度を分析する
- Q4 サービス提供時間に対する実際に使えた時間の割合を表すSLA項目は → 可用性（稼働率）
- Q5 FログとDBで突き合わせるデータ項目は → 入力されたキーワードと問合せキーワード

※採点講評：設問1は正答率が低かった。設問4(2)は本文にない項目を書いた解答が散見された。
