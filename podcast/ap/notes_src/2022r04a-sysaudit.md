# 令和4年度秋期 午後 問11 システム監査／テレワーク環境の監査

## 1. 覚えるキーワード3つ
- 利用終了届の照合：テレワーク環境の利用者管理は、従業員の異動・退職などの状況と、終了届の記載内容を照らして確かめる
- 紛失日と届出日の照合：貸与PCの紛失日と、システム部への届出日を確かめて、点検が適切に行われたかを検証する
- 是正状況のモニタリング：点検で不備が見つかったら、システムリスク管理の部門が、不備事項の是正状況をモニタリングする

## 2. 状況
- マンション管理のY社で、テレワークの拡大に伴い、不適切なWi-Fiの利用による個人情報漏えいと、PCの紛失が起きた。しかし、各部の点検結果では不備が報告されていなかった。
- 内部監査部のシステム監査チームが、各部の点検が実効性をもっていたかを検証する。
- 利用終了届や紛失届との照合、Web会議システムの追加の検討、是正のモニタリングなどを確かめる。

## 5. 用語

| 用語 | 一言の意味 |
|---|---|
| システム監査人 | 専門性と客観性をもって、情報システムを点検・評価する人 |
| 貸与PC | 会社が従業員に貸し出すPC |
| セキュリティ点検 | 各部門が自部門のセキュリティ管理状況を確かめること |
| 是正 | 見つかった不備を正すこと |
| モニタリング | 状況を継続して確かめること |
| 実効性 | 計画や統制が、実際に効果をもつこと |

## 6. 思い出しクイズ
- Q1 利用者管理の確認で、終了届と照らす情報は → 従業員の異動、退職などの状況
- Q2 貸与PCの紛失で、突き合わせる2つの日付は → 紛失日とシステム部への届出日
- Q3 点検の実効性を確かめる対象は → セキュリティ点検が適切に実施されたか
- Q4 不備事項について、システムリスク管理部門が行うことは → 是正状況のモニタリング
- Q5 設問1の正答率が低かった理由は → 業務部門のシステム管理者の役割の理解不足

※採点講評：設問1は正答率が低く、利用者を管理するシステム管理者の役割の理解が問われた。設問2は正答率がやや低く、点検の実効性を確かめる手続を導くことが求められた。設問5は正答率が平均的だった。
